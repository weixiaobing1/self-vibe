# AI 学习助手 APP - 完整项目开发文档

# 项目名称

MindFlow AI

一个面向程序员/大学生的 AI 学习助手

【开发环境说明】 - 本地已通过 Docker Compose 部署 MySQL 8.0 和 Redis 7.0 -\- MySQL 地址：localhost:3306，数据库名 mindflow，root 密码 123456，字符集 utf8mb4，时区 Asia/Shanghai - Redis：地址 localhost:6379，密码 123456，已开启 AOF 持久化 - 项目技术栈：Java + Spring Boot 3.x + MyBatis Plus + RedisTemplate + Spring AI - 目标：实现 MindFlow AI 学习助手后端（用户模块、笔记模块、AI 生成模块、复习计划模块）

核心目标：

帮助用户：

- 随时记录知识
- AI 自动整理
- AI 自动总结
- AI 自动生成复习计划
- AI 自动生成面试题
- 手机端随时使用

项目要求：

- 必须可以部署
- 必须可以生成手机 APP
- 必须前后端分离
- 必须使用 Java 后端
- 必须有 AI 元素
- 必须适合个人开发
- 必须适合 Claude Code 辅助开发

# 二、核心功能设计

# 1. AI 快速记录

用户可以：

- 输入文字
- 语音转文字
- 上传代码
- 上传图片

例如：

“今天学了 Spring AOP”

“Redis 缓存穿透还没理解”

“这个代码为什么空指针异常”

---

# 2. AI 自动整理知识

AI 自动完成：

- 分类
- 提取重点
- 生成摘要
- 提炼知识点
- 提炼关键词
- 建立关联

例如：

输入：

今天学了 IOC 和 DI。

AI 输出：

知识点：

- IOC：控制反转
- DI：依赖注入

关联技术：

- Spring
- Bean
- AOP

难度：

初级

---

# 3. AI 自动生成面试题

例如：

“IOC 和 DI 有什么区别？”

“Spring 如何实现 IOC？”

“Bean 生命周期是什么？”

支持：

- 初级题
- 中级题
- 高频面试题
- 八股文

---

# 4. AI 自动复习系统

根据遗忘曲线：

自动提醒用户复习。

例如：

- 今天复习 SpringMVC
- 三天后复习 Redis
- 七天后复习 JVM

AI 自动调整复习频率。

---

# 5. AI 学习日报

每天自动生成：

- 今日学习时长
- 今日学习内容
- 学习趋势
- 学习效率
- 薄弱知识点

甚至：

分析拖延倾向。

---

# 6. AI 代码解释

用户上传代码。

AI 自动：

- 解释代码
- 分析逻辑
- 解释报错
- 生成注释
- 提供优化建议

例如：

上传：

@Autowired
private UserService userService;

AI 自动解释：

- 什么是 IOC
- 什么是 DI
- Spring 如何注入 Bean

---

# 7. AI 学习路线生成

例如：

“我想学习 Java 后端。”

AI 自动生成：

- 学习路线
- 学习顺序
- 推荐项目
- 推荐技术栈
- 推荐视频
