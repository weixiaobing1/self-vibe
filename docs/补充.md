### 22.1 艾宾浩斯遗忘曲线算法（必须严格实现）

public class ReviewAlgorithm {

// 复习间隔（天），对应记忆分数区间

private static final Map<Integer, Integer> INTERVAL_MAP = new HashMap<>();

static {

INTERVAL_MAP.put (90, 1);    // 90-100 分：1 天后复习

INTERVAL_MAP.put (70, 3);    // 70-89 分：3 天后复习

INTERVAL_MAP.put (50, 7);    // 50-69 分：7 天后复习

INTERVAL_MAP.put (30, 14);   // 30-49 分：14 天后复习

INTERVAL_MAP.put (0, 1);     // 0-29 分：1 天后重新复习

}

/**

- 生成下次复习时间

- @param currentScore 当前记忆分数

- @return 下次复习时间

  

  */

  

  public static LocalDateTime generateNextReviewTime (int currentScore) {

  

  int interval = INTERVAL_MAP.entrySet ().stream ()

  

  .filter (entry -> currentScore >= entry.getKey ())

  

  .map (Map.Entry::getValue)

  

  .findFirst ()

  

  .orElse (1);

  

  return LocalDateTime.now ().plusDays (interval);

  

  }

  

  }

### 23.1 统一返回结果类

@Data

@AllArgsConstructor

@NoArgsConstructor

public class Result<T> {

private int code;       // 响应码：200 成功，其他失败

private String message; // 响应信息

private T data;         // 响应数据

public static <T> Result<T> success (T data) {

return new Result<>(200, "操作成功", data);

}

public static <T> Result<T> success() {

return success(null);

}

public static <T> Result<T> error(int code, String message) {

return new Result<>(code, message, null);

}

public static <T> Result<T> error(String message) {

return error(500, message);

}

}

### 23.3 全局异常处理器

@RestControllerAdvice

@Slf4j

public class GlobalExceptionHandler {

@ExceptionHandler(BusinessException.class)

public Result<Void> handleBusinessException (BusinessException e) {

log.error ("业务异常：{}", e.getMessage (), e);

return Result.error (e.getCode (), e.getMessage ());

}

@ExceptionHandler(MethodArgumentNotValidException.class)

public Result<Void> handleParamException(MethodArgumentNotValidException e) {

String message = e.getBindingResult().getFieldError().getDefaultMessage();

return Result.error(ErrorCode.PARAM_ERROR.getCode(), message);

}

@ExceptionHandler(Exception.class)

public Result<Void> handleException (Exception e) {

log.error ("系统异常：{}", e.getMessage (), e);

return Result.error (ErrorCode.SERVER_ERROR);

}

}

## 二十八、前端 Flutter 对接补充规范

1. Token 存储：使用 flutter_secure_storage 安全存储 Access Token 和 Refresh Token
2. 请求拦截器：自动在请求头添加 Authorization: Bearer {token}
3. 错误处理：统一拦截 401 错误，自动刷新 Token，刷新失败跳转到登录页
4. 文件上传：使用 dio 实现分块上传，支持进度显示
5. 离线缓存：使用 hive 缓存笔记和复习任务，联网后自动同步
